# 记忆、上下文与来源治理

工作台 v2 复用固定 DeerMem 文件事务和本人 FTS5；Go 负责策略、来源、范围、作业及投递屏障，Python 只承担内部存储和受限模型适配。没有新增向量数据库，也没有开放上游无门禁自动记忆。

> 2026-11-09 已部署既有云端实例。本地真实供应方闭环 16 项、独立 Codex 同根两轮、浏览器矩阵 33 项和旧镜像升级保留均有独立记录。云端另完成 22 项可信 HTTPS/API 和 13 项浏览器检查；这些结果不代表研究对照或云端到家庭 Agent 的新闭环。

## 策略与范围

新账号采用有版本的产品默认。旧关闭缺乏来源时仍保持关闭，明确暂停不被启动或刷新覆盖；安装 owner 的升级选择由独立、带版本比较的操作记录。自动整理与使用已有记忆分别控制。

临时话题的负向策略先于运行时话题创建落库。真实 run 的本人身份及话题决定读写边界，客户端标记不能放宽；整个临时话题不注入、不采集。

个人偏好可跨话题复用。项目要求使用本人私有项目标签，与共享项目 ACL 或 Worker 授权不同；只有当前明确提及的项目或原话题绑定才参与召回。阶段要求限定原话题，默认三十天有效；明确新阶段会更新原槽位，完成关注后过期。过期事实仍可管理。

## 两条规范来源

普通聊天核对持久 runs、threads_meta、owner、incarnation、interactive 来源、消息 ID 和正文哈希；编辑回放、归档、共享项目或缺失身份的记录不采集。首页 Router 使用 Go 已接纳的本人 Inbox，另存完整输入已检查的证明；截断输入、外部事件、工具输出和助手回答不能提升为本人表达。

全局 Router 只归纳稳定个人事实与明确命名的项目要求。未绑定具体工作的话题阶段要求留在本次上下文，不写成全局阶段记忆。最终 Router 提示词在角色隔离之后重新加入当前允许的个人记忆；背景 Assessor 不接收它。

## 快路径与持久作业

明确低风险普通表达走确定性快路径，不要求记忆口令。一般归纳走持久、有界作业：每 owner 每 UTC 日最多四个模型准入，实例合计三十二个；总输入按四千 UTF-8 字节保守限制，包含固定提示词，输出最多五百一十二 tokens，无工具、无模型重试。复用已有对话模型，不增加记忆专用配置。

调用前冻结模型、策略和额度，持久标记供应方调用状态；内部动作先返回调度回执，由最多两个后台调用写入规范结果，避免 HTTP 的三十秒期限中断整理。等待模型时不持有 SQLite 写锁。结果落库前再次核对来源和策略。丢失回执只核对缓存结果；未知结果不换模型、不重发。快速整理与模型整理使用不同队列，避免慢调用阻塞清晰偏好。

作业只存来源引用、哈希和状态，不复制原始消息。输出最多三条，必须有原文证据、合法类别和范围；认证材料及敏感反例在模型前后检查。候选正文在接纳后清除，实际生效以单事实存储操作回执为准。

首次整理限定最近七天、最多十个获准话题，每话题最多五条最近消息。水位与条目持久化，重复调度不增加作业；停止与撤销阻止迟到写入。历史结果不覆盖当前槽位，撤销仅删除来源仍属于该次导入的新增事实。恢复中断的枚举不会无界重扫。遗忘水位以前的消息不重新导入。

## 纠正、遗忘与读取

同一回答偏好更正复用原事实 ID，以版本比较更新，接纳时停止旧值注入。模糊的最近指代只能在本话题唯一定位时处理；歧义显示选择入口。

遗忘先建立单向屏障，再清理正文、索引及使用关联。暂停、排除话题、来源撤销和账号变化使旧作业版本失效。管理入口在暂停时仍可使用。此机制不声称擦除备份、原始聊天或已经发给供应方的内容。

检索在 FTS 排名前限制 owner、范围、有效期与允许 ID；最终注入前再核对版本和来源。索引不可用时不退回全文件扫描。个人事实与持续工作的检索配额不同，不能相互推断。

## 确定性首页与评估

首页仅从规范资料、近期待办、工作与任务证据构建快照，按待回应、新结果、未决事项排序；已读、当地次日暂缓及不再提醒持久保存。GET 和刷新不触发整理模型或 Native。

记录某条事实进入了模型上下文，不代表模型一定按它回答。评估要分别报告来源准确、范围隔离、保存成功、召回、实际回答遵守、延迟和调用数。当前合成测试不是人类研究或模型质量收益证明，PRD 的可用性和质量阈值仍是待测目标。
