# 开始第一项工作

第一次使用建议从范围清楚、结果容易检查的小目标开始。

![ 从一个目标到可检查的结果](/deermate/docs/diagrams/quickstart.svg)

先看完整路径，再按下面的步骤开始。普通问答不必配置执行设备。

## 1. 登录并交代目标

进入工作台，在任务输入区写下目标，然后进入新对话。也可以使用侧栏的「新对话」。说明背景、需要的结果和完成条件。

> 示例：请整理这个公开网页的三个主要观点，每条附上来源，并列出资料中尚未回答的问题。

这是一条示例指令。能否读取网页，以当前环境加载的工具及实际工具结果为准。

## 2. 明确执行范围

如果需要修改代码，先确认管理员已注册项目，并完成 [设备与 Agent 授权](/docs/guide/authorization)。说明项目、要修改的行为和验收标准。

> 示例：在已授权的示例项目中修复空列表显示，保留已有交互，运行项目配置的验证命令并返回结果。

在对话里写入一个本机路径不会自动授予访问权限。设备、项目与操作必须在实际授权范围内。

## 3. 查看进展与结果

在工作台的近期任务或原对话中打开结果。重点检查当前状态、修改说明、产物和独立验证。没有任务记录时，先确认本次只是普通聊天，还是已经接纳执行任务。

「已配置」描述配置事实；「在线」描述连接观测；「执行结束」与「独立验证通过」也分别表达不同结果。请用实际证据判断是否满足目标。

## 4. 在原对话继续

需要补充时，在原对话中说明明确的下一步，例如「请再覆盖没有数据时的说明文案」。已绑定的 Codex 对话会在条件满足时继续原生会话，保留上一轮结果。

如果页面显示结果未知或要求核对，先查看原结果。不要通过新建对话重复发送同一次可能已执行的操作。详细说明见 [对话与任务结果](/docs/guide/conversations)。

## 接下来

将需要长期跟进的对话加入 [今日关注](/docs/guide/focus)，把希望长期保留的偏好保存到 [个人记忆](/docs/guide/memory)。新版可直接进入「秘书与工作」，详见 [持续秘书与工作](/docs/guide/continuous)。
