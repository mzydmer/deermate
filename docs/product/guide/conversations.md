# 对话与任务结果

对话保存交流上下文，任务记录一次具体执行。原生会话是执行 Agent 保留的工作上下文；这些记录各有身份和生命周期。

## 从助手首页接着聊

登录后在「助手」的输入框交代事情，或在近期事项中点「接着聊」回到原话题。「我的工作」查看执行与待答复事项；「全部对话」保留完整列表。普通话题会按个人设置使用和整理长期记忆。

只谈这次、不希望读写长期记忆时，从首页点「临时对话」。整个话题保持临时，后续追问也一样；普通聊天记录仍保存，临时不等于无痕。创建回执丢失时再点一次会核对原话题。

## 连续追问

一个已绑定的执行对话固定关联一个原生 Codex 会话。后续轮次在同一项目与工作区中继续，每轮保留独立结果和验证记录。首条消息可自动生成标题，也可在界面中改名。

在原对话写清下一步。已有轮次忙碌、等待输入、需要恢复或授权发生变化时，系统可能拒绝新一轮；先处理当前状态。另一项独立目标使用新对话，避免混用上下文。

## 如何读状态

| 页面含义 | 你可以如何处理 |
| --- | --- |
| 排队、准备或执行中 | 等待进展，必要时查看原记录 |
| 等待答复 | 阅读原问题，在受支持的入口回答 |
| 执行结束 | 检查结果与独立验证，不只看总结 |
| 待检查或没有验证 | 人工检查产物，补充验收条件 |
| 执行失败 | 阅读失败证据，确认原因后再决定下一步 |
| 请求停止、取消中 | 等待执行端确认；此时仍可能运行 |
| 已取消 | 查看已产生的部分结果与停止记录 |
| 结果未知、需要恢复 | 核对原操作，避免重复执行 |

不同入口可能使用不同的状态名称。独立验证只有存在实际记录且退出码为零时才能显示通过；未配置验证命令时不会凭 Agent 的回答认定通过。

## 检查结果的顺序

1. 核对目标、项目与执行轮次，确认是你要检查的工作。
2. 阅读摘要，查看补丁或可用产物。
3. 查看独立验证命令、退出码和输出，确认覆盖了你的完成条件。
4. 若仍需调整，在原对话给出具体下一步。

验证命令通过只证明该命令在本次运行中的结果，不保证覆盖所有业务情况。

## 连接中断以后

网络超时不能证明任务尚未开始。优先打开原对话、原任务，或使用可用的「核对原结果」。系统通过原任务和会话身份查找已有结果；无法确认时会保留不确定状态。

当前只承诺已有实现范围内的 Codex 连续性。其他执行器和所有中断情况的兼容性仍需单独验证。

## 在工作列表中核对

在「我的工作」搜索标题，或按处理中、待回应、已结束筛选，再点「查看详情」。宽屏在右侧展示详情，空间不足时使用浮层；按 Esc 关闭后，键盘焦点回到打开详情的按钮。

详情分别列出执行结果、独立验证与部署情况。「执行结束 · 未验证」不能当作验证通过，「部署未确认」也不代表已经上线。长输出在独立区域中滚动，可复制任务和话题标识继续核对。
