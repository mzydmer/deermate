# 设备与 Agent 授权

设备接入与执行授权共同决定 Agent 能在哪里完成哪些工作。授权能力已完成本地验收，并在既有云端实例通过登录、权限与管理页面检查。实际设备接入和执行仍需本机确认，其他实例须核对版本。

## 配对与本机确认

由有权限的用户打开「Agent 授权」，按页面引导申请设备接入，选择项目、操作范围、截止时间及到期任务策略。在实际设备上完成配对和该版本的本机确认。

设备的原生 Agent 登录仍保留在设备上。不要把 Codex 登录文件、配对凭据或令牌粘贴到聊天和项目源码中。

## 三种状态分别检查

| 状态 | 检查什么 |
| --- | --- |
| 授权有效 | 当前授权版本、项目、操作与期限符合要求 |
| 连接可达 | 最近一次观测时能连接到该设备 |
| 执行就绪 | 执行器、协议、本机确认和项目条件满足本次工作 |

设备能连通不代表已获执行权限。授权尚未确认、已过期、被撤销或项目不匹配时，新执行会被拒绝。

## 续期、取消与撤销

续期会产生需要核对的新授权版本，按页面要求再次在本机确认。未完成的申请可取消；不再使用的有效授权应撤销。

到期时对已接纳任务采用你选择的策略。撤销或到期不能直接证明正在运行的进程已经停止；检查原任务结果和停止回执。

## 持续秘书的额外条件

持续秘书需要兼容持续任务的设备协议，以及该版本的本机确认。旧授权不会自动扩大。缺少有效设备、项目权限或协议时，先完成这些条件，再从原工作发起明确操作。

当前普通账号仍受既有执行角色限制。功能页面存在不代表已经开放共享设备或所有账号执行。
