# 认识 DeerMate

DeerMate 是你的私人助手。在「助手」交代事情，在「我的工作」查看进展，在「关于你」查看习惯和要求；获授权的执行 Agent 在指定设备和项目中完成具体工作。

## 工作台中的几个概念

- **秘书**：接收目标、组织上下文、提出下一步并跟进结果。
- **对话**：一次持续交流的上下文。独立目标建议使用独立对话。
- **任务**：某次具体执行，有状态、结果和验证记录。同一对话可以包含多轮任务。
- **工作**：持续秘书 Alpha 中跟踪长期目标的对象，可关联事件、决策和执行对话。
- **设备与授权**：约束执行发生在哪里、可以操作哪个项目，以及何时到期。

## 当前可用范围

当前是私人 Agent 系统研究 Alpha。基础聊天、Codex 多轮会话、任务结果、个人关注与显式记忆已有实现。不同环境的版本和配置可能不同；功能出现在文档中，不代表当前实例已启用。

工作台 v2 为新账号默认开启记忆，支持普通表达、私有项目标签和阶段范围；已有暂停选择保留。助手默认可用，观察来源与自动执行需另行设置；设备授权已在既有云端实例完成相关页面与权限检查，实际设备是否可执行以授权与就绪检查为准。

Claude 执行适配、多人共享项目记忆以及通用无人值守仍未提供完整实现或验收。请查看 [变更日志](/docs/changelog) 了解各阶段的交付边界。

## 使用前准备

准备可登录的账号，由管理员确认模型和所需工具已配置。涉及代码执行时，还需要注册项目、有效设备授权、已确认的执行器和可用的原生登录。只做普通问答时，不必先配置执行设备。

文档中心提供客户使用指南与技术方案。接口参考和部署指南暂不对外提供。

## 界面与状态阅读

统一界面采用黑灰主操作与中性表面；完成状态使用蓝色，并同时提供文字或图标。颜色不是授权、连接或独立验证成功的唯一依据。窄屏工具栏按组换行，宽表格在自身区域横向滚动；设置和详情保持可阅读区域。此视觉调整不改变既有任务与权限流程。

组件化工作台在桌面保留完整侧栏，平板缩为图标导航，手机从顶栏打开抽屉。顶栏的文档和主题按钮提供文字提示；主输入随内容增高，长输出和宽表格在各自区域滚动。该改造已于 2026-11-13 部署到既有云端实例，其他自托管实例以实际升级版本为准。
