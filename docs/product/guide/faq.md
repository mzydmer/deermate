# 常见问题

## 为什么文档里的功能在页面中找不到

先确认当前实例版本、账号角色和功能开关。新版新账号默认开启记忆与建议，可在「关于你 → 记忆设置」查看和调整；既有账号保留原选择。助手可直接使用并沿用对话模型。部分能力仅完成本地验收。文档更新时间与实例升级日期可以不同。

## 已经连接设备，为什么还不能执行

连接可达只是观测结果。还要检查授权期限、版本、本机确认、项目与操作范围、执行器登录和协议兼容性。持续秘书还要求支持持续任务的设备协议。

## 任务显示完成，为什么没有验证通过

执行结束与独立验证分别记录。没有配置验证命令、证据不足或需要人工检查时，不能声称验证通过。查看本轮实际验证记录和产物。

## 提交后超时，是否应该再发一次

先打开原任务或点击「核对原结果」。超时可能发生在任务已经接纳之后。未知结果需要核对原操作；换新对话或新 ID 重发可能造成重复工作。

## 请求停止后设备断线，任务是否已停止

需要执行端确认才可认定停止。设备离线时可能继续运行。查看原任务的最后已知状态，恢复连接后核对停止回执。

## 为什么记忆没有保存或搜索不到

在「关于你」检查自动整理与使用已有记忆两个设置、记录范围和整理状态。清楚的偏好会直接保存，复杂表达可能等待有界整理；临时对话不读写长期记忆，普通提问也不会都保存。每天整理额度用完或来源失效时页面会说明，聊天仍可继续。搜索使用关键词，可以尝试原文中的词语。

## 为什么今日关注没有内容

新版首页从本人最近的话题、关注与实际工作中选最多三件事；新账号还没有历史时直接交代第一件事即可。临时话题、不可读来源和不再提醒的事项不展示。没有数据时不会编造进展。

## Claude、邮件和任意外部服务都可以使用吗

这些能力需要各自的适配与授权，不能从支持 Codex 或某个 MCP 连接推断全部可用。Claude 执行适配、邮件工作流及通用桌面自动化尚未完成本产品的完整验收。

## 如何反馈问题

整理实例版本、页面入口、发生时间与时区、预期和实际结果，以及可公开的错误文案或任务引用。提交前移除密码、令牌、Cookie、私人对话和项目机密。尽量提供不会触发重复执行的复现步骤。
