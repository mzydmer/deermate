# 工具与数据连接

工具让秘书搜索资料、读取公开网页，或访问你明确授权的服务。每个连接保留自己的身份、数据权限和服务限制。

## 公开搜索与网页读取

管理员在侧栏打开「工具与连接」，确认公开搜索和网页读取显示「已加载」。随后可以在聊天中要求搜索、读取并附上来源。

> 示例：搜索这个开源项目的公开资料，读取官网，按功能和限制整理，并为每条结论提供来源。

免费服务可能限流。搜索词会交给搜索服务，公开 URL 会交给网页读取服务；不要将私人资料、密码或令牌放入搜索词和链接。网页读取不接受本机、私网、云元数据等受限地址。

## 添加数据连接

如需 GitHub、Notion 或数据库等服务，由有权限的用户进入「能力中心 → 工具与集成」，配置服务提供的 MCP 地址及所需授权。数据库需对应的 MCP 服务，不能直接把数据库连接串当作工具地址。

返回「工具与连接」，刷新并点击「测试连接」。该检查初始化连接并发现工具，不读取业务数据。成功后查看实际工具名称；空列表表示当前服务没有提供工具。

## 在对话中使用

下一条消息明确说明使用哪个连接、读取什么范围、返回什么结果。是否读到数据、是否执行成功，以实际工具结果为准。

| 显示状态 | 含义 |
| --- | --- |
| 已配置 | 已保存连接定义 |
| 连接成功 | 当前初始化与工具发现成功 |
| 实际工具调用成功 | 本次具体读取或操作成功 |

连接成功不能证明所有业务数据都可访问。平台连接由管理员维护，个人连接使用当前账号定义；不会自动借用其他账号的权限。

## 失败时如何处理

先检查服务是否可用，再检查地址、授权与协议。确认后重新测试。网页与工具返回的文字都是外部资料，不能替你授予新的执行、发送、合并或发布权限。
