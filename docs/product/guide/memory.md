# 关于你与记忆管理

在正常对话里提到习惯和要求就好，不必说“请记住”。例如“以后回答先给结论”，或者“DeerMate 控制端使用 Go”。助手会在后台整理适合保留的内容。新账号默认开启；升级前已有的暂停选择会保留。

> 工作台 v2 已于 2026-11-09 部署到既有云端实例。其他自托管实例须升级对应版本，具体范围见变更日志。

## 看看记住了什么

侧栏打开「关于你」。这里能搜索记录，按个人、项目或近期话题筛选，查看原话、记录时间、适用范围和最近加入过哪些对话的上下文。加入上下文并不能证明模型一定采纳了它。

个人偏好可以在不同话题使用。明确命名的项目要求只在谈到该项目时使用；当前阶段的要求只属于原话题，并设有效期。项目名称只是本人记忆的整理标签，不会授予设备或仓库权限。

点击「查看来源与用途」核对原话；原话来自助手首页时，入口回到助手。来源删除、归档、换代或失去访问权后，不再显示原文或用于回答。过期记录仍可管理，但不再用于回答。

## 记错了就改

点击「纠正」修改内容，保存后旧版本立即停止使用。正常聊天中再次明确同一类回答偏好，也会更新原记录。

“忘记刚才那条记忆”仅在当前对话能唯一定位最近一条记录时直接处理；无法确定时会提示到「关于你」选择，不会猜其他话题的记录。保存后的轻提示提供来源和撤销新增入口；以实际完成状态为准，正在整理不代表已经记住。

「忘记」先停止使用，再清理记忆正文及索引。原聊天记录、执行记录、备份和已发给模型的上下文不随单条遗忘删除。后台迟到结果不能恢复旧记忆。

## 暂停或用临时对话

展开「记忆设置与个人资料」。两个设置分别控制「自动整理聊天中的偏好与要求」和「回答时使用已有记忆」，可以独立调整。暂停后仍然能查看、修改和忘记。

首页点「临时对话」，会先创建一个独立话题。整个话题不读取、不新增长期记忆；聊天记录照常保留，不是无痕聊天。来源详情里的「这个话题不再记忆」停止该话题今后的整理，已有记录仍可逐条忘记。

## 接回最近的资料

首次升级或使用时，后台只检查最近七天、最多十个本人话题，每个话题最多五条最近消息。页面显示整理状态，支持停止和撤销本次新增；已有记录和后来本人纠正的内容不随撤销删除。更早的历史仍保存在原对话中。

清晰的偏好使用快速整理，其余内容受每天最多四次模型整理的限制；达到额度不影响聊天。读取或刷新页面不发起模型调用。结果未知时只核对已有回执，不会重复调用模型。

## 称呼、时区和数据边界

称呼和时区在「记忆设置与个人资料」中修改。不填称呼就只问好，不会用邮箱猜名字。未设置时区时使用 UTC，也可点击使用设备时区。

记忆仅使用本人、当前仍获准的内容。密码、验证码等已识别的认证材料不写入记忆；不能保证任意文本中的敏感内容均能识别。健康、财务和第三方资料不默认整理为长期画像。外部模型仍可能接收任务需要的上下文，自托管不等于模型供应方看不到提示词。
