# 个人设置与记忆

个人记忆用于保存本人明确提供的偏好、目标和背景。当前支持显式事实与关键词检索；自动语义提取和共享项目记忆仍在后续范围中。

## 设置称呼和时区

在工作台展开「个人设置与记忆」，保存称呼和时区。首页问候、简报日期与今日关注会使用这些设置。

## 保存、查看与搜索

开启个人记忆后，手动保存一条事实，选择偏好、目标或背景等类型。每条尽量只表达一个明确事实，例如「我希望项目说明优先使用中文」。不要保存密码、访问令牌或身份凭据。

可以查看和搜索本人记录。当前搜索采用关键词，不能保证同义改写或单字中文都能匹配；没有搜索结果时尝试原文中的关键词。

## 从对话明确记忆

「明确记忆指令采集」是独立、默认关闭的开关。开启后，在新的聊天消息中使用明确指令，例如「请记住：我的周报优先写结论」。普通问答不会自动成为记忆。

只有来源与身份等检查通过的内容才会被接纳，并受配额约束。保存请求已接纳与记录已完成写入是不同阶段；查看页面实际状态及原对话来源。

## 纠正、关闭与遗忘

- **纠正**：直接修改事实，避免仅在另一段聊天中口头否定旧记录。
- **关闭个人记忆**：停止相关采集与注入，隐藏目标推荐；仍可管理已有记录。
- **遗忘**：先阻止旧事实被继续使用，再跟踪清理状态。接纳遗忘不等于底层清理已完成。

来源失效时，页面隐藏旧正文并说明原因。后台迟到结果不能把已遗忘的内容重新引入上下文。

## 数据使用边界

当前个人记忆只读取本人且仍获准的事实。使用外部模型时，任务所需上下文可能被发送给该模型供应方。自托管不意味着供应方看不到提示词，也不代表任意文本中的敏感信息都能自动识别。
