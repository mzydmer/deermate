# 今日关注与跟进

今日关注把你明确选择的历史对话放回首页，展示可核对的进展。首页读取与刷新使用已有记录，不会主动启动新的代码任务。

## 添加关注

1. 在工作台展开「管理关注」。
2. 选择已有对话，或粘贴本站历史对话链接。
3. 填写希望跟进的目标，点击「关注这个对话」。

关注不会因对话离开最近列表而消失。首页最多展示三项，优先提示失败、待输入和未读变化；每项提供原对话、记录时间和核对时间。

## 只读跟进

展开「跟进这个话题」，查看固定问题，再点击「一键只读跟进」。回答完成后进入「查看跟进结果」。这一次跟进不开放执行工具。

该动作会使用当前配置的聊天模型，可能产生供应方费用。首页展示或刷新本身不调用整理模型。

## 继续执行具体下一步

对于已关联 Codex 任务的关注，展开「继续执行具体下一步」，填写本次明确要求并提交。系统先核对原项目、执行器、会话和权限，只续接一轮。

连接受阻、任务忙碌或结果未知时，先处理原记录。网络中断后使用「核对原结果」，不要换新目标重复提交。

## 调整关注与建议

使用「标记已读」「今天先不看」「暂停」「完成关注」「不再关注」调整列表。不再关注会保留原对话。来源删除、归档、换代或不可读时，旧卡片内容会隐藏。

若希望获得长期目标相关的新话题，先开启个人记忆、保存目标，再单独开启「根据长期目标推荐新话题」。先查看问题和推荐理由，点击后才创建新对话；新话题以只读方式开始。

称呼、日期和今天的截止时间采用个人设置中的时区；未保存时使用 UTC。需要时可选择设备时区。
