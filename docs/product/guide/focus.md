# 助手首页与最近的事

登录后进入「助手」。首页用本人资料中的称呼和时区问好，展示最多三条有依据的近期事项，下面只有一个交代事情的输入框。「关于你」摘要放在旁边，小屏时在下方显示，近期事项默认收起，可点展开；输入始终留在主区。

> 新版首页正在本地验收，尚未发布到公网实例。旧的关注记录和原对话仍会保留。

## 先看上次的事

首页读取已关注的话题、最近七天的本人对话和持续工作记录。先显示待答复或失败的事情，再显示新结果，最后是未完成或可继续的话题。有多少依据就显示多少，不补示例卡片。

每项显示原记录的时间。连接不通时说明这是上次核对的状态；失去来源访问权时隐藏原文。执行结束、验证通过和已经发布是不同结果，不能由其中一个推断另一个。

点击「接着聊」回到原对话，打开页面不会自动发送。你的下一句话继续使用原会话。点击「看看结果」进入「我的工作」，查看实际执行和证据。

## 交代一件新事

直接在首页输入。助手沿用已有对话模型和持久秘书入口，按项目和工作分派；执行前仍检查已有设备授权。记忆不会额外授予电脑、邮箱、发布或付款权限。

需要独立讨论时点「开始新话题」。不希望使用或增加长期记忆时点「临时对话」。网络中断且结果未知时核对原操作，不换新目标重复派单。

## 调整提醒

打开某项会记录已读；「今天先不看」按资料时区暂时收起，到当地次日恢复；「不用再提醒」持久隐藏该项，不删除原对话或工作。单纯刷新不会重复调用模型或执行器。

「我的工作」保留工作安排、明确追问、停止和原操作核对；最近对话的原生执行记录另列。更早的记录仍可从原对话进入。

保存了明确长期目标、且允许目标建议时，旁边显示最多两个讨论问题及依据。点「开始这个话题」才创建一次只读讨论；「不感兴趣」会记住反馈。单纯查看建议不调用模型。
