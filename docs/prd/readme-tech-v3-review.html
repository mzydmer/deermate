THE IDEA

让架构成为第一眼。

一个持续响应的 Router，一组独立执行的 Worker。请求穿过明确的接纳边界，工作留在自己的机器，记忆与证据把每一轮连起来。

科技感来自系统如何运转：信号的分叉、权限的边界、会话的延续，以及可检查的结果。
