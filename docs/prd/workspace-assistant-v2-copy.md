## 语气与用词

像熟悉工作内容、靠谱的同事：知道现在讨论哪件事，清楚做到了哪一步，有事直接说。

- 先写具体事项或结果，再写下一步。比如「首页还有两个方案没定，接着看看？」。
- 一句话只承担一件事。来源、时间、状态用短标签补充，不挤进开场白。
- 少说助手如何了解用户；把实际记下的偏好、正在做的事摆出来。
- 按钮写动作：「查看结果」「保存更正」「核对原结果」。导航写目的地：「个人助手」「我的工作」「关于你」。
- 只在需要时解释边界，优先写用户下一步能做什么。状态不明就写待核对，不能说已开始或已完成。
- 保留必要的来源、范围、时间、暂停和隐私说明；不把这些说明换成泛泛的安慰。
- 不卖萌、不自夸，不用营销口号；原本清楚的文案不强求改写。

| 场景 | 统一名称 | 用法 |
| --- | --- | --- |
| 记忆页面与首页摘要 | 关于你 | 页面与导航名称 |
| 保存并供以后参考的内容 | 记忆 | 说明、管理和反馈统一使用 |
| 记忆分组 | 个人偏好／项目与目标／近期事项 | 「个人偏好」避免与页面名重复 |
| 当前回答实际使用的内容 | 本次参考／信息 | 包括当前话题要求，不全部称为长期记忆 |
| 修复结果 | 修复完成／测试通过／尚未部署 | 三项分别陈述 |
| 同一件事继续讨论 | 继续这个话题 | 打开现有话题并聚焦输入，本身不发送新请求 |
| 另起一件事 | 新话题／新建话题 | 必须真的创建新话题；不以此代替继续已有事项 |
| 暂停新的记忆整理 | 暂停自动记忆 | 与「停止使用已有记忆」分别展示 |
| 整个话题不使用、不新增记忆 | 临时对话 | 从临时入口新建，不能叫无痕对话 |

## 评审中的一致性问题

1. **两个方案的数量。** 首页标题原写「还有一个方向」，正文写两个方向，手机和工作列表也写两个。统一为两个方案；若实际不是二选一，标题必须随真实事项调整。
2. **新话题建议已区分。** 右栏改为「看看其他助手的首页怎么做」，理由是「给首页方案找几个参考。」，按钮为「新建话题」。这是一项独立研究，已有首页方案仍从「继续这个话题」进入。
3. **当前要求与长期记忆。** 「这次只做 PRD」仍只属于本话题，参考数量改叫「信息」，避免把三条全部暗示为长期记忆。
4. **暂停范围已明确。** 图中暂停状态只指自动整理；是否参考旧记忆由另一项设置决定，页面分别展示两项状态。
5. **临时对话范围已明确。** 从临时入口新建话题，整个话题都不读取、不新增长期记忆。既有普通话题的「本次不使用」仅排除当前回答中的指定记忆，是另一项操作；两者不共用状态。
6. **来源过时和不可用。** 过时但仍可访问的记录可保留原时间；来源被撤销、删除或失去访问权时隐藏原文，停止参考，不能共用一个旧快照说明。
7. **删除范围。** 忘记应立即停止参考，并分别显示删除进度。原对话、执行记录和备份并不一起删除，必须保留完整说明入口。
8. **费用承诺。** 原图的「不重复计费」超出了单个页面状态可确认的范围，改为「聊天保持可用，整理状态单独显示」。已接纳但结果未知的模型请求只核对，避免盲目重发。
