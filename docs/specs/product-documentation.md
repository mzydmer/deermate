# 产品文档中心

- 状态：Implemented locally；验证结果见下方，未发布。

- 更新：2026-11-04。

## 问题与结果

工作台缺少面向客户和技术读者的统一文档入口，现有工程文档混有部署命令、接口和历史验收，不能直接作为客户手册。新增「产品文档」入口跳转 `/docs`，按使用指南、技术方案与变更日志组织内容。参考点金文档中心的受众分流，内容以 DeerMate 实现为准。

## 内容与边界

- 使用指南：概览、首次工作、对话与结果、关注、记忆、工具、设备授权、持续秘书、FAQ。
- 技术方案：组件与边界、可靠执行、记忆与来源治理、研究评估方法。分别标注实现、验收和待开展实验。
- 变更日志：客户可见变化、启用条件和发布范围；未部署内容写入待发布。
- 不提供接口参考和部署指南；保留既有内部工程文档，不将其自动公开。

## 实现

根目录已有页面继续进入工作台。在登录页、工作台顶栏与侧栏增加入口。独立 `/docs` 只提供版本化公开内容，不读取账号、对话或任务，不要求登录；访问工作台仍沿用原登录保护。

`docs/product/catalog.json` 与 Markdown 为唯一内容源；`scripts/product_docs.py` 生成前端 JSON，验证链接、来源、标题和同步状态。页面复用现有安全 Markdown 渲染、共享 tokens、主题，支持正文关键词搜索、目录锚点、相邻文章和复制 Markdown。未知路由返回 404。

AGENTS 直接引用文档政策，PR 模板要求影响说明，CI 比较本次变更范围。代码变更需产品 Markdown 更新，或有理由的无需更新记录；生成文件不能单独通过门禁。合并强制依赖远端分支保护配置，当前本地任务不修改远端仓库设置。
