# M4.4c–e · 关注、证据简报与首页动作

状态：个人范围的确定性首页闭环已本地合成验收，2026-11-02；完整语义采集/模型作业和真实 Native 新入口验收保留后续。按用户要求连续推进，步骤验证后继续，不以单一子步骤代替完整首页闭环。

需求沿用 FR-024–FR-028 和完整规格 MEM-01–MEM-21；边界见 [主规格](m4-personal-memory-briefing.md)、[ADR 0013](../decisions/0013-memory-backed-personal-briefing.md)。

## 顺序

1. Go 关注主题：本人选择已有对话，保存 incarnation、范围、标题/目标、优先级、版本、已读/暂停/今天不看。超过最近 20 条仍保留；取消关注不删除对话。
2. 证据与今日关注：从固定共享 SQLite 中的本人线程/任务读取有界投影；只将真实独立验证记为通过。最后已知状态、记录核对与执行端同步时间分开。来源删除/换代/权限或范围变化后隐藏旧内容；归档默认不进入首页。
3. 首页动作：服务端固定规范问题与来源，持久 intent 后才接纳；重复点击核对同一结果。只读跟进和新话题的运行在模型及工具入口执行能力限制，不能仅靠提示词；执行续接必须明确下一步、沿用原会话/权限并最多一个子任务。
4. 可选新话题：仅对本人有效目标提出可解释建议；采用建议不反向采集兴趣。确定性读模型不调用整理模型，额外模型预算为零；语义整理按后续独立预算接入。

## 存储与 API

Go 继续拥有公开接口、资料、关注/已读/静音、快照及动作账本。Python 只适配运行时受限动作和执行器会话。复用现有 DeerMem、运行时任务、单会话绑定与 ordinary task driver。

- `/api/me/attention-topics`：本人列表/显式关注；`/{id}` 使用版本更新、暂停/恢复、完成、取消、今天不看、已读。
- `GET /api/me/briefing`：确定性当前读模型及版本；不会发起模型、Native 或外网请求。最多三项今日关注、两项可解释新话题。
- `POST /api/me/briefing/refresh`：重核本人现有来源；数据无变化复用语义版本，不创建整理 run。
- `/api/me/briefing/actions`：准备/查看/执行服务端 intent，来源失效拒绝；已接纳后只核对，不盲重放。

最多 50 个未删除关注、20 个活动主题/用户。查询按 owner、thread、incarnation 与范围先过滤；只读取有界最新记录，不导入原始聊天。简报日期和“今天不看”采用保存的 IANA 时区。记忆关闭不阻止原有任务/显式关注展示；新话题建议独立开关。

## 验证

分别验证本人/跨用户、超最近页、来源删除/归档/换代、验证失败与跟踪过期、空/部分失败、时区/日界/DST、已读/静音版本及同版本零额外模型/Native。再验证 intent 双击/未知结果、只读对抗工具调用、新话题命名/不采集建议、原生会话续接/权限/忙碌边界。

Go mod/vet/race/无 CGO 构建、固定 Gateway/SQLite/图契约、前端类型/构建和实际浏览器分别记录；真实供应方、真实 Native、云端与 2 GiB 实机性能不能由本地 Fake 验收推断。

实际结果：[脱敏收据](../verification/personal-home-2026-11-02.json)记录 41 项固定契约、43 项实际 API、14 项浏览器检查及完整构建/部署子集。Codex 续接当前由 pinned Submitter 测试替身验证会话一致和丢失回执屏障；不能替代真实 Go→Gateway→Worker 验收。
