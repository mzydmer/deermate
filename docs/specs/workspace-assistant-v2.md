# 私人助手工作台 v2：实施规格

状态：Accepted，2026-11-09。用户已批准按文案修订后的 [PRD](../prd/workspace-assistant-v2.md) 连续实现、本地验收、推送和线上部署，无需阶段性复审。开发基线为远端 main `780173a`；[计划](workspace-assistant-v2-plan.md)区分实现、验证和发布。

## 产品与样式

保留 PRD 的信息架构与文案，样式以当前根目录 design.md 为准。静态稿直接读取规范中的浅深色及字号/行高，替代早期冻结色值。实际产品使用已生成 tokens 与 app 组件；不引入第二份主题。保留 240px 侧栏、384px 详情、窄屏抽屉、单一主输入；首屏不再显示团队宣传、Gateway 状态和多份输入。

首页 `/workspace` 展示本人称呼、当地问候、最多三条有来源的事项、唯一消息输入与“关于你”摘要。`/workspace/work` 管理工作与实际证据；`/workspace/memory` 管理偏好、项目要求和近期事项。原聊天和设置链接继续有效。对话仍保持一个 incarnation 对应一个执行器原生会话；打开页面不派发任务。

## Go 控制与现有存储

Go 负责默认策略、迁移来源、话题模式、范围、整理预算/作业、候选接纳和删除屏障。Python 内部适配器复用 DeerMem 文件事务及本人 FTS5，处理受限模型整理；不启用上游无门禁自动记忆，不新增向量数据库。普通回答与 Router 继续使用原链路，不为记忆另调用回答模型，也不让记忆获得工具权限。

- 版本化默认：新用户默认允许自动整理和使用记忆；旧策略标记其来源。旧明确暂停继续保持；无法判断的旧关闭保留暂停。现有安装 owner 的新默认选择来源是本次用户授权，由显式迁移步骤记录，不批量推定其他账号同意。
- “自动整理”和“使用已有记忆”分别控制；关闭任一相关策略后，旧作业的策略版本失效，不能延迟写回。
- 临时入口创建独立话题，服务端在第一次消息前保存模式。整个话题不读取、不新增长期记忆；普通聊天记录仍保留。客户端字段不能绕过当前模式或扩大检索范围。
- 每条事实保留类别、来源、适用范围、版本和时间。个人偏好可跨话题使用；项目要求只在相应项目中使用；当前阶段要求只在本话题有效，完成/到期后不再用于新回答。
- 资料中的姓名/时区仍是唯一主源。无可靠称呼时只问好，不从邮箱生成姓名。

## 整理、预算与来源

仅本人新提交并被实际接纳的交互消息可以产生候选。普通对话验证 runs、threads_meta、owner、incarnation、消息 ID/哈希与 interactive 来源；Router 只使用 Go 已接纳的本人 Inbox 消息，外部事件/工具输出/回放/助手回答均不能提升为用户表达。

明确低风险偏好使用确定性快路径，无“请记住”前缀要求。其他内容由持久、有界整理作业处理：每天每 owner 最多四个模型作业；限制输入约 4k tokens、输出 512 tokens，复用已配置对话模型。调用前冻结模型与额度；不持有 SQLite 写锁等待模型。未知接纳不重发；存储投递可按原操作 ID 核对。达到预算不阻挡聊天和已生效记忆。

作业只保存规范来源引用及哈希，避免复制原消息中的认证材料；已识别密码/验证码/密钥/完整身份支付信息在模型调用前排除，模型输出在接纳前再检查。健康、财务及第三方资料不默认归纳为长期画像。默认不新增对话正文遥测。

首次接回本人现有资料、事实、工作和最近话题；异步整理最近七天、最多十个当前获准话题。范围/状态可查，可停止/撤销。作业幂等；首页 GET/重复刷新不启动新的模型或执行器请求。更广历史整理属于 P1，不作为此次发布前置。

## 纠正、排除和遗忘

明确自然更正可定位到唯一事实时替换；有歧义才询问。纠正立即停止旧版本注入。忘记先建立单向屏障再删除正文、索引及依赖内容；撤销新增、排除话题、来源撤权同样阻止迟到作业复活。管理页在记忆暂停时仍可用。原聊天、执行记录、备份及已发给模型的内容不包含在单条遗忘内。

## 首页与连续对话

首页读取确定性快照：先展示待本人回应，再展示可核对的新变化，再展示近期未决事项。没有依据时不补假卡片。原话题继续只打开并聚焦输入；发送后走原会话。全局需求经原持久 Router，新话题只创建一次；预览、查看结果与执行必须保持不同语义。未知结果只核对原操作。

来源过时保留原核对时间；撤销/失去访问权则移除原文。已结束、测试通过、已部署分开呈现。已读、今天不看和不感兴趣的反馈持久保存，不删除原话题。手机与浅深色使用同一事实和状态。

## 验收与发布

完整验收矩阵沿用 PRD 的 WS2-01–21，见计划；不能以静态设计或 Fake 运行替代真实模型、Native 和升级验收。模型质量阈值是目标，须报告实际结果；无依据不得声称科研收益。

先通过 Go race/构建、Python 与固定 Gateway 契约、设计/token/文档门禁、TypeScript/生产构建和有针对性的恢复测试。再在独立本地部署上验证真实登录、记忆闭环、原会话连续性、错误/空/临时/暂停、390/768/1280/1440px、浅深色和键盘。全部通过后提交远端，备份现有云端账号/数据/镜像，部署已验证版本并核对数据保留与公网读写；失败使用原镜像/备份回退，不自动恢复旧设备授权。
